# AGENTS.md — Pocket Beacon

Прототип веб-приложения для обмена геолокацией в локальной Wi-Fi сети.
Язык интерфейса и комментариев в коде — русский.

## Стек

- Бэкенд: Node.js (>=20) + Express + Socket.IO + better-sqlite3
- Фронтенд: vanilla JS + Leaflet (раздаётся из node_modules, без CDN и без сборки)
- HTTPS: самоподписанный сертификат, генерируется при старте (`server/cert.js`)
- Хранилище: SQLite в `data/` (users, sessions, location_history)
- Установщик: Inno Setup (`installer/pocketbeacon.iss` + `scripts/build-installer.ps1`)

## Команды

- `start.bat` (или `scripts/start.ps1`) — запуск из исходников: скачивает портативный
  Node в `.runtime/`, ставит зависимости, стартует сервер
- `npm start` — прод-запуск (HTTPS на 0.0.0.0:$PORT)
- `npm run dev` — то же с --watch
- `npm run dev:http` — dev-режим: HTTP на http://localhost:3444 без сертификата
  (геолокация работает, т.к. localhost — secure context; НЕ для LAN)
- `npm run reset-admin` — сброс пароля администратора (новый пароль в консоль)
- `npm run build:installer` — сборка `build/PocketBeacon-Setup-<version>.exe`
  (требуется Inno Setup 6)
- `node scripts/test-socket.js` — e2e-проверка реального времени (нужен запущенный dev:http)

## Ключевые инварианты (не ломать)

1. Геолокация в браузере требует secure context → в LAN только HTTPS, порт из `PORT`.
2. Бан проверяется на каждый запрос/сокет-сообщение по свежей записи из БД,
   сессии баннутого удаляются (`deleteSessionsForUser`), сокеты кикаются (`kickUser`).
3. `is_hidden=1` ⇒ координаты не принимаются, не хранятся в истории, позиция стёрта,
   трек не отдаётся (`/api/history/:id` → пусто).
4. История пишется с прореживанием (см. `historyMin*` в config.js), хранится 24 ч.
5. Весь пользовательский текст на фронте вставляется только через textContent (XSS).
6. Элементы поверх карты должны иметь z-index > 1000 (панели Leaflet).
7. `.env`, `data/`, `certs/`, `.runtime/`, `build/`, `logs/` — в .gitignore.
8. Защитные ограничения админки: нельзя банить/удалять себя и последнего админа.
9. Лаунчер и установщик ставят зависимости с `--ignore-scripts` → все зависимости
   обязаны работать без install-скриптов (better-sqlite3 — за счёт пребилдов
   в пакете). Не добавлять зависимости, требующие нативной сборки.
10. `scripts/*.ps1` и `installer/*.iss` — в UTF-8 **с BOM** (иначе PowerShell 5.1
    и ISCC ломают кириллицу). При правке этих файлов BOM сохранять!
11. В `.env` не хранить пользовательские данные и пароли. Админ по умолчанию —
    `admin`/`admin`; пока пароль стандартный, `maybePromptAdminPassword` (index.js)
    при каждом запуске предупреждает и в TTY предлагает сменить пароль
    (ввод скрытый). `reset-admin.js [пароль]` — сброс на admin или установка своего.
    В БД — только bcrypt-хеши.
12. Логирование на сервере — только через `server/logger.js` (консоль + файл),
    не голым console.log (исключение: QR-код и интерактивные prompt'ы — только консоль).
13. Порт проверяется до старта (`resolvePort` в index.js): занят → TTY-пrompt
    или автовыбор свободного, выбор сохраняется в `.env`. Проверка порта —
    и на 0.0.0.0, и на 127.0.0.1 (Windows позволяет двойное занятие).
14. Режим наблюдателя — чисто клиентский (localStorage `pb_observer`): геолокация
    не стартует, координаты стираются через `/api/location/clear`. «Наблюдатели»
    в списке = онлайн (живой сокет) без координат, вычисляется на сервере.
15. Версия хранится в `package.json`; `build-installer.ps1` берёт её оттуда —
    при релизе бампить только package.json.

## Тестирование

Автотестов нет; проверка — curl-запросы к API + `scripts/test-socket.js` +
ручная проверка UI через `npm run dev:http` + симуляция релиза (копия
git-отслеживаемых файлов в чистую папку, запуск start.bat без Node в PATH).
Установщик проверяется тихой установкой: `setup.exe /VERYSILENT /NORESTART`.
