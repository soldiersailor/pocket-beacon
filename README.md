# Pocket Beacon

Локальное веб-приложение для обмена геолокацией внутри Wi-Fi сети. Пользователи регистрируются, видят друг друга на общей карте с именами, могут скрыть своё местоположение и посмотреть треки перемещений за сутки. Администратор может банить и удалять пользователей.

## Возможности

- 🗺️ Общая карта (Leaflet + OpenStreetMap) с метками пользователей в реальном времени (Socket.IO)
- 👤 Регистрация и вход по логину/паролю (bcrypt, сессии в SQLite)
- 🙈 Кнопка «Скрыть меня» — пользователь исчезает с карты, его трек перестаёт писаться и показываться
- 👣 История перемещений за 24 часа (с прореживанием точек), трек любого видимого пользователя доступен всем
- 📷 QR-код для быстрого входа с телефона (страница `/qr` и QR в консоли сервера)
- 🛡️ Админ-панель: бан/разбан, удаление, назначение админов (бан действует мгновенно, включая активные сессии)
- 🔒 HTTPS из коробки — самоподписанный сертификат генерируется автоматически при первом запуске

## Требования

- **Windows 10/11** для сервера. Node.js ставить не обязательно — `start.bat` скачает портативный сам (либо установите Node.js 20+ с https://nodejs.org)
- Компьютер и телефоны в **одной Wi-Fi сети**
- Интернет на устройствах (тайлы карты грузятся с серверов OpenStreetMap)

## Быстрый старт (для пользователя релиза)

1. Скачайте архив релиза и распакуйте.
2. Запустите **`start.bat`** двойным кликом.
3. При первом запуске скрипт сам: скачает портативный Node.js в `.runtime\` (в систему ничего не установит), поставит зависимости, создаст `.env` со случайными секретами и **покажет логин/пароль администратора** — сохраните их.
4. Windows предложит разрешить доступ node.exe к сети — **разрешите** (частная сеть).
5. В консоли появится адрес вида `https://192.168.1.50:3443` и QR-код.
6. Откройте `https://<адрес>:3443/qr` на компьютере и отсканируйте QR телефоном.

## Запуск из исходников (для разработчика)

```bash
npm install
cp .env.example .env   # Windows: copy .env.example .env
# отредактируйте .env: SESSION_SECRET и ADMIN_PASSWORD
npm start
```

Для разработки без сертификата есть `npm run dev:http` — HTTP-версия на `http://localhost:3444` (геолокация работает только на localhost; с телефонов — только основной HTTPS-режим).

### Предупреждение о сертификате

Геолокация в браузерах работает только по HTTPS, поэтому сервер использует самоподписанный сертификат. При первом входе браузер покажет предупреждение — это ожидаемо:

- **Android / Chrome:** «Дополнительно» → «Перейти на сайт»
- **iPhone / Safari:** «Показать подробности» → «перейти на сайт»

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3443` | Порт HTTPS-сервера |
| `HOST_IP` | авто | IP сервера в LAN. Заполните вручную, если автоопределение выбрало VPN/WSL-адаптер |
| `SESSION_SECRET` | — (обязательно) | Случайная строка для подписи сессий |
| `ADMIN_LOGIN` | `admin` | Логин администратора (создаётся при первом запуске) |
| `ADMIN_PASSWORD` | — (обязательно) | Пароль администратора |

## Решение проблем

| Проблема | Решение |
|---|---|
| Телефон не открывает адрес | 1) Разрешите node.exe в брандмауэре Windows. 2) Проверьте, что на роутере выключена изоляция клиентов (AP/Client Isolation) — частая настройка гостевых сетей. 3) Убедитесь, что телефон не на мобильном интернете |
| QR ведёт не на тот адрес | IP определился неверно (VPN, виртуальные адаптеры). Задайте `HOST_IP` в `.env` и перезапустите |
| «Не удаётся определить позицию» | Первый GPS-фикс занимает время; в помещении точность 20–100 м — это нормально. Точки с точностью хуже 100 м не отправляются другим |
| Позиция «замерла» | При выключенном экране браузер приостанавливает геолокацию — смотрите подпись «N мин назад» |
| Запретил геолокацию и всё пропало | Значок замка в адресной строке → разрешить «Местоположение» → обновить |
| На ПК «Нет доступа к геолокации», хотя в браузере всё разрешено | Геолокация выключена в самой Windows: Параметры → Конфиденциальность → Расположение → «Изменить» → включить определение местоположения + «Разрешить приложениям доступ к вашему местоположению». Затем обновить страницу |
| Сервер «уснул» посреди демо | Отключите сон в настройках электропитания Windows |
| IP сервера сменился (DHCP) | Просто перезапустите сервер — сертификат и QR перевыпустятся автоматически |

## Структура проекта

```
start.bat        запуск для пользователя релиза (двойной клик)
scripts/
  start.ps1      лаунчер: портативный Node -> npm install -> .env -> старт
  test-socket.js e2e-проверка реального времени
server/          бэкенд (Express, Socket.IO, SQLite)
  index.js       точка входа (HTTPS, QR в консоль)
  app.js         сборка Express-приложения и Socket.IO
  dev-http.js    dev-режим: HTTP на localhost без сертификата
  config.js      настройки из .env
  db.js          SQLite: схема, запросы, сид админа, очистка истории
  routes.js      REST API
  sockets.js     реальное время
  auth.js        мидлвары авторизации и rate-limit
  cert.js        генерация самоподписанного сертификата
  net.js         определение LAN IP
  store.js       хранилище сессий в SQLite
  geo.js         валидация координат, гаверсинус
public/          фронтенд (vanilla JS + Leaflet)
  js/app.js      авторизация, сокет, геолокация, админка
  js/map.js      карта, маркеры, треки
  js/api.js      fetch-обёртка
  qr.html        страница с QR-кодом
.runtime/        портативный Node.js (скачивается start.bat, не коммитится)
data/            БД SQLite (не коммитится)
certs/           сертификаты (не коммитится)
```

## Приватность и ограничения прототипа

- Пароли хранятся как bcrypt-хеши; история перемещений — 24 часа и удаляется автоматически
- «Скрыть меня» = полная приватность: позиция стирается, трек не пишется и не показывается
- Приложение рассчитано на **доверенную локальную сеть** и до ~30 пользователей. Не выставляйте его в интернет: самоподписанный сертификат, открытая регистрация и пароли без требований к сложности для публичного развёртывания не подходят
