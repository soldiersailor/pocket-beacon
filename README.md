# Pocket Beacon

Локальное веб-приложение для обмена геолокацией внутри Wi-Fi сети. Пользователи регистрируются, видят друг друга на общей карте с именами, могут скрыть своё местоположение и посмотреть треки перемещений за сутки. Администратор может банить и удалять пользователей.

## Возможности

- 🗺️ Общая карта (Leaflet + OpenStreetMap) с метками пользователей в реальном времени (Socket.IO)
- 👤 Регистрация и вход по логину/паролю (bcrypt, сессии в SQLite)
- 🟡 **Вход через Яндекс** (опционально) — один клик вместо регистрации; аккаунт создаётся автоматически
- 👁️ Режим наблюдателя — вход без геолокации и без запроса на неё: смотрите за другими, не делясь своим местоположением
- 🙈 Кнопка «Скрыть меня» — пользователь исчезает с карты, его трек перестаёт писаться и показываться
- 👣 История перемещений за 24 часа (с прореживанием точек), трек любого видимого пользователя доступен всем
- 📷 QR-код для быстрого входа с телефона (страница `/qr`, кнопка «QR» на карте и QR в консоли сервера)
- 🛡️ Админ-панель: бан/разбан, удаление, назначение админов — всё применяется мгновенно, с уведомлением пользователя (бан действует даже на активные сессии)
- 🔒 HTTPS из коробки — самоподписанный сертификат генерируется автоматически при первом запуске
- 🔌 Если порт занят — сервер сам предложит свободный и запомнит его
- 📋 Логи одновременно в консоль и в файл `logs/app.log`

## Требования

- **Windows 10/11** для сервера
- Компьютер и телефоны в **одной Wi-Fi сети**
- Интернет на устройствах (тайлы карты грузятся с серверов OpenStreetMap)

## Установка (рекомендуется)

1. Скачайте **`PocketBeacon-Setup-x.y.z.exe`** со [страницы релизов](https://github.com/soldiersailor/pocket-beacon/releases).
2. Запустите установщик (права администратора не нужны), при желании отметьте ярлык на рабочем столе.
3. Запустите **Pocket Beacon** с ярлыка. Всё уже внутри: Node.js, зависимости — интернет для установки не нужен.
4. Войдите под **`admin` / `admin`**. При запуске сервер предложит сменить стандартный пароль прямо в консоли (или позже: `npm run reset-admin`).
5. Windows предложит разрешить доступ node.exe к сети — **разрешите** (частная сеть).
6. Откройте `https://<адрес>:3443/qr` на компьютере и отсканируйте QR телефоном.

Удаление — стандартное («Установка и удаление программ»); удаляются все данные, включая БД и логи.

## Запуск из исходников (без установщика)

1. Скачайте архив исходников (Source code zip) и распакуйте.
2. Запустите **`start.bat`** двойным кликом — скрипт сам скачает портативный Node.js в `.runtime\` (в систему ничего не установит) и поставит зависимости. Первый запуск требует интернет.
3. Дальше — как в п.4–6 выше.

Для разработки: `npm install`, затем `npm start` (или `npm run dev:http` — HTTP-версия на `http://localhost:3444` без сертификата; геолокация работает только на localhost).

### Предупреждение о сертификате

Геолокация в браузерах работает только по HTTPS, поэтому сервер использует самоподписанный сертификат. При первом входе браузер покажет предупреждение — это ожидаемо:

- **Android / Chrome:** «Дополнительно» → «Перейти на сайт»
- **iPhone / Safari:** «Показать подробности» → «перейти на сайт»

## Режим наблюдателя

Для тех, кто хочет только смотреть за другими (например, с рабочего ПК):

- отметьте «Режим наблюдателя» на экране входа — геолокация не запрашивается вовсе;
- либо нажмите «Продолжить без геолокации» на экране ошибки доступа к местоположению.

Наблюдатель не появляется на карте, но виден другим в списке «Наблюдатели». Вернуться к обычному режиму — кнопка «Включить геолокацию» в шапке.

## Вход через Яндекс (опционально)

Если в `.env` заданы `YANDEX_CLIENT_ID` и `YANDEX_CLIENT_SECRET`, на экране входа появляется кнопка «Войти через Яндекс». Пользователь разрешает доступ — аккаунт создаётся автоматически (логин берётся из Яндекса, при занятости добавляется суффикс), пароль ему не нужен. Обычный вход по логину/паролю продолжает работать.

### Как включить (один раз, ~5 минут)

1. Откройте https://oauth.yandex.ru под своим Яндекс-аккаунтом → **«Зарегистрировать новое приложение»**.
2. Название: `Pocket Beacon`. Платформа: **«Веб-сервисы»**.
3. **Redirect URI** — добавьте один-единственный:

   ```
   https://soldiersailor.github.io/pocket-beacon/oauth.html
   ```

   Это статичная страница-переадресовщик из репозитория (GitHub Pages). Она не зависит от IP и порта вашего сервера, поэтому **Яндекс-вход продолжает работать при смене IP и при авто-выборе другого порта** — править кабинет больше никогда не понадобится.
4. **Доступ**: отметьте «Доступ к логину, имени и аватару» (`login:info`) — больше ничего не нужно.
5. Сохраните и скопируйте **ClientID** и **Client secret** в `.env`:

```
YANDEX_CLIENT_ID=ваш_id
YANDEX_CLIENT_SECRET=ваш_секрет
```

Перезапустите сервер — кнопка появится.

> Как это работает: реальный адрес сервера путешествует внутри `state` и проверяется по сессии, а страница на GitHub Pages просто возвращает браузер на ваш сервер. Если GitHub Pages недоступен, Яндекс-вход временно не сработает (обычный вход по паролю работает всегда). Если вы перевели проект в другой аккаунт/репозиторий — задайте свою страницу через `YANDEX_RELAY_URL` в `.env`.

## Настройки (.env)

Файл `.env` создаётся автоматически при первом запуске. Хранит только технические настройки (паролей пользователей в нём нет — они в БД в виде bcrypt-хешей).

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3443` | Порт HTTPS-сервера. Если занят — сервер предложит свободный и запишет его сюда |
| `HOST_IP` | авто | IP сервера в LAN. Заполните вручную, если автоопределение выбрало VPN/WSL-адаптер |
| `SESSION_SECRET` | авто | Секрет подписи сессий. Генерируется автоматически |
| `YANDEX_CLIENT_ID` / `YANDEX_CLIENT_SECRET` | выкл | Креды приложения Яндекс OAuth для входа через Яндекс (см. раздел ниже) |
| `ADMIN_LOGIN` | `admin` | Логин администратора (создаётся при первом запуске) |
| `ADMIN_PASSWORD` | `admin` | Необязательно: начальный пароль админа. Пока пароль стандартный, сервер при запуске предлагает его сменить |

Смена пароля администратора: при запуске сервера (ответьте `y` на вопрос в консоли), либо `npm run reset-admin` (сброс на `admin`), либо `npm run reset-admin -- новыйпароль`. В установленном приложении: `runtime\node.exe scripts\reset-admin.js` из папки приложения.

## Логи

Все события (запуск, регистрации, входы, баны) пишутся в консоль и в `logs/app.log`. При превышении 5 МБ лог ротируется в `app.1.log`.

## Решение проблем

| Проблема | Решение |
|---|---|
| Телефон не открывает адрес | 1) Разрешите node.exe в брандмауэре Windows. 2) Проверьте, что на роутере выключена изоляция клиентов (AP/Client Isolation) — частая настройка гостевых сетей. 3) Убедитесь, что телефон не на мобильном интернете |
| Порт занят | Сервер сам предложит свободный порт (в консоли — подтвердите Enter'ом; без консоли выберет автоматически) и запомнит его в `.env` |
| QR ведёт не на тот адрес | IP определился неверно (VPN, виртуальные адаптеры). Задайте `HOST_IP` в `.env` и перезапустите |
| «Не удаётся определить позицию» | Первый GPS-фикс занимает время; в помещении точность 20–100 м — это нормально. Точки с точностью хуже 100 м не отправляются другим |
| Позиция «замерла» | При выключенном экране браузер приостанавливает геолокацию — смотрите подпись «N мин назад» |
| Запретил геолокацию и всё пропало | Значок замка в адресной строке → разрешить «Местоположение» → обновить. Либо «Продолжить без геолокации» |
| На ПК «Нет доступа к геолокации», хотя в браузере всё разрешено | Геолокация выключена в самой Windows: Параметры → Конфиденциальность → Расположение → «Изменить» → включить. Либо войдите в режиме наблюдателя |
| Сервер «уснул» посреди демо | Отключите сон в настройках электропитания Windows |
| IP сервера сменился (DHCP) | Просто перезапустите сервер — сертификат и QR перевыпустятся автоматически |
| Забыл пароль админа | `npm run reset-admin` — пароль сбросится на `admin`; сервер предложит сменить его при запуске |

## Приватность и ограничения прототипа

- Пароли хранятся как bcrypt-хеши в локальной БД; в `.env` паролей нет
- Администратор по умолчанию — `admin`/`admin`; сервер при каждом запуске напоминает сменить стандартный пароль, пока он не сменён
- История перемещений — 24 часа и удаляется автоматически
- «Скрыть меня» = полная приватность: позиция стирается, трек не пишется и не показывается
- Приложение рассчитано на **доверенную локальную сеть** и до ~30 пользователей. Не выставляйте его в интернет: самоподписанный сертификат, открытая регистрация и пароли без требований к сложности для публичного развёртывания не подходят
